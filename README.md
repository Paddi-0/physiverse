# 万象物理 PHYSIVERSE

可编程 3D 物理沙盒：公式驱动的力场、30 种材质、网格建模工坊与 DC 电路实验室。

## 直接游玩

https://paddi-0.github.io/physiverse/

## 玩法速览

- 30 种材质：钢、铝、钛合金、橡胶、玻璃、石墨烯、气凝胶、蓝宝石等，密度、弹性、摩擦、硬度、抗拉、脆性、电阻率、导热全部参与模拟。
- 90 条物理公式，分 9 类；`F = m*g` 等公式可直接改写，力场会真实改变世界。
- 14 种形体与建模工坊：网格吸附放置、旋转、静态/动态结构、撤销，可搭弹簧、梁、板、塔、多米诺。
- 电路实验室：14×9 网格 MNA 求解器，放置电源、电阻、电容、电感、二极管、开关并实时求解。
- 10 个预设世界：地球、月球、火星、零重力、反重力、强引力、电场、风暴、慢动作、弹跳。

## 运行

单文件、离线可用。下载 `index.html` 后用浏览器打开即可，移动端触控与桌面端鼠标均可操作。
